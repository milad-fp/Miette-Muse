# 🥐 Miette & Mise — Bakery Website

## Bakery & Pastry Shop — Responsive Website

A modern and elegant bakery website designed to showcase freshly baked pastries, signature desserts, bakery products, and the story behind the brand.

The website focuses on a warm visual experience, attractive product presentation, elegant typography, and a responsive layout to create a beautiful online presence for a bakery.

## 📖 About The Project

A responsive bakery website created with a focus on visual presentation, elegant typography, and a warm, modern user experience.

The website presents a fictional bakery brand with sections for featured pastries, bakery categories, the brand story, customer experience, newsletter subscription, and contact information.

The design combines soft colors, rounded imagery, large typography, and carefully structured layouts to create a premium and welcoming bakery identity.

A small amount of JavaScript is also used to control the responsive sidebar, allowing users to open and close the navigation menu on smaller screen sizes.

## 📱 Responsive Design

The website is fully responsive and designed to provide a consistent experience across different screen sizes.

The layout adapts from a multi-column desktop design to tablet and mobile layouts.

On smaller screens, the navigation transforms into a responsive sidebar that can be opened and closed using JavaScript.

All major sections, including the hero area, product showcase, categories, story section, newsletter, and footer, adapt to different screen sizes.
